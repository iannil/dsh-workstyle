# dsh-workstyle 多页面重设计

> 日期：2026-11-08
> 状态：设计已确认，等待文档审阅

## 1. 目标与范围

将当前单一全宽面板升级为多页面的工作方式管理器，服务三类同等重要的场景：

- 个人使用：确认当前项目和会话实际加载了什么。
- 工作方式作者：维护规则、技能、预设、模板并审阅蒸馏结果。
- 团队分发管理员：管理包版本、作用域快照、导出和安装。

本轮覆盖侧栏入口、主导航、多页面信息架构、运行台、包管理、蒸馏审阅、度量、分发，以及规则编辑、空状态、错误状态和首次使用路径。

现有后端接口和数据模型保持兼容。只有在页面需要包列表、导出历史或报告历史而现有接口无法提供时，才补充最小接口。

## 2. 已确认的产品决策

1. 默认首页是“当前环境”，优先回答“这一刻什么在生效、是否可信”。
2. 一级导航采用环境优先骨架，结合工作流式首页动作和清晰的包详情结构。
3. 三类用户从同一套导航进入各自任务，不为个人、作者、管理员复制三套产品。
4. 主视觉性格采用“仪器台”：安静、精确、低饱和，状态和变化是视觉重点。
5. 包内参考资源保持只读；项目级叠层是主要编辑面。
6. 所有编辑成功后都必须重新计算作用域和注入指纹，结果回到运行台可验证。
7. 度量继续使用可复算代理指标，不推断模型是否遵守规则。

## 3. 信息架构

```text
工作方式
│
├── 运行台                         /run
│   当前加载结果、作用域链、注入预览、待办
│
├── 工作方式包                     /packs
│   包列表、启用状态、版本、来源、最近变更
│   └── 包详情                     /packs/:id
│       规则、技能、预设、模板、只读/可编辑来源
│
├── 蒸馏审阅                       /distill
│   本地扫描、报告窗口、建议规则、采纳/撤销
│
├── 度量                           /metrics
│   代理指标、数据口径、时间窗口、基线比较
│
└── 分发                           /distribute
    导出包、作用域快照、安装命令、导出历史
```

### 3.1 共享环境上下文

固定侧栏只承载一级导航。所有页面共享当前作用域选择器和环境上下文，切换页面不丢失当前项目、会话或预设。

```text
当前环境：FDE 交付
项目：dsh-workstyle
作用域：全局 → 项目 → 会话
已注入：7 条规则 · 40 个技能
指纹：85aead453ee3                         [刷新]
```

### 3.2 页面关系

```text
运行台 ──查看详情──> 包详情
运行台 ──处理待办──> 蒸馏审阅 / 度量 / 包详情
包详情 ──切换预设──> 运行台即时更新
包详情 ──编辑项目规则──> 运行台重新生成指纹
蒸馏审阅 ──采纳规则──> 包详情 + 运行台
分发 ──导出当前快照──> 包详情 / 当前作用域
```

运行台只做确认、跳转和快速切换，不承担完整编辑。包详情是规则作者的主工作面；蒸馏审阅和度量拥有独立垂直空间；分发不再挤在页面底部。

## 4. 视觉系统

### 4.1 色彩 token

| Token | Hex | 用途 |
| --- | --- | --- |
| 墨黑 | `#14171C` | 主要文字、强动作、深色主题实体面 |
| 纸灰 | `#F4F0E8` | 深色主题反色文字与关键标记 |
| 暖白 | `#FBF9F5` | 浅色页面底色 |
| 琥珀 | `#95550F` / `#E3A660` | 当前状态、变化、可操作链接 |
| 蓝灰 | `#47739A` | 会话层或外部来源 |
| 警示红 | `#A44A3F` | 实际错误或阻塞 |

琥珀是唯一品牌强调色，不铺满整块卡片。蓝灰只区分会话层或外部来源，警示红不用于普通低指标。

### 4.2 字体与排版

- 系统中文无衬线用于所有界面文字。
- 等宽字体只用于指纹、规则 id、路径、安装命令和注入文本。
- 标题不使用装饰性衬线，保证多页面任务连续性。
- 内容左对齐，正文行长控制在约 70 个字符以内。
- 数字、时间和指纹使用等宽数字。
- 共享页面 token：容器圆角 12，控件圆角 8，徽标使用小圆角而非泛化胶囊。
- 动效只用于页面切换、保存完成和展开/折叠反馈；尊重 `prefers-reduced-motion`。

### 4.3 可访问性

- 所有导航和页面切换使用语义链接或按钮，并提供键盘焦点。
- 状态不只依靠颜色表达，同时显示文本和来源。
- 深色和浅色主题都需要检查文字、边界、焦点环的对比度。
- 空状态提供下一步动作；错误状态说明原因和可恢复操作。

## 5. 核心页面线框

### 5.1 运行台 `/run`

```text
┌ 工作方式 ─────────────────────────────── [作用域 ▾] [刷新] ┐
│ 当前环境：FDE 交付    项目：dsh-workstyle    指纹 85aead453ee3 │
├──────────────────────────────────────────────────────────────┤
│ 运行状态                                                       │
│ 已注入 7 条规则       启用 40 个技能       预设 FDE 交付        │
│ 全局 6  ·  项目 +1  ·  会话 -1           最近蒸馏 8 小时前      │
├──────────────────────────────────────────────────────────────┤
│ 需要处理                                                     │
│ 3 条建议待审   2 条缺证据   1 个作用域冲突             [查看]  │
├──────────────────────────────────────────────────────────────┤
│ 注入证明                                                       │
│ systemPrompt / dsh-workstyle.rules                            │
│ sha256 85aead453ee3   610 字符   7 条规则   [展开文本] [复制] │
├──────────────────────────────────────────────────────────────┤
│ 快速切换                                                       │
│ [FDE 交付] [写书] [RC 探讨]                                  │
└──────────────────────────────────────────────────────────────┘
```

运行台必须展示真实注入文本、指纹、作用域来源和待办跳转。它不再重复完整规则正文。

### 5.2 工作方式包 `/packs` 与包详情 `/packs/:id`

包库显示包名、版本、来源、启用状态、规则/技能数量和最近变更。包详情采用页签或子导航：规则、技能、预设、模板。

```text
┌ 返回工作方式包   FDE 工程工作方式                 [导出] [更多] ┐
│ v0.1.0 · 内置参考包 · 7 条规则 · 40 个技能 · 3 个预设            │
├──────────────────────────────────────────────────────────────┤
│ [规则 7] [技能 40] [预设 3] [模板 3]                            │
├──────────────────────────────────────────────────────────────┤
│ 项目叠层：dsh-workstyle/.dsh/workstyle.json          [编辑]    │
│ ───────────────────────────────────────────────────────────────│
│ ✓ 先方案后实现                         全局     [启用] [展开]   │
│ ✓ 证据优先                             全局     [启用] [展开]   │
│ + 不要动 pack/reference                项目     [编辑] [展开]   │
│ — 中文短句                             会话     [已停用]        │
└──────────────────────────────────────────────────────────────┘
```

包内规则和技能只读。项目规则可新建、编辑、删除。正文、来源和证据默认折叠，展开后保持同一左缘。

### 5.3 蒸馏审阅 `/distill`

页面结构为报告头、扫描范围与隐私说明、建议规则列表、证据摘要。建议规则支持选择、采纳、撤销；采纳后返回包详情和运行台验证指纹。

### 5.4 度量 `/metrics`

使用数字、口径和来源组成的指标行或小卡片，不做装饰性大图表。每项指标必须显示公式、分母、数据窗口和样本不足提示。禁止出现“遵守率”“违反率”等推断词。

### 5.5 分发 `/distribute`

页面按顺序展示：导出包、是否包含项目作用域快照、安装命令、包目录、最近导出记录。导出成功后提供文件路径和复制动作；失败时保留选择并显示重试。

## 6. 数据流与接口边界

```text
进入插件
  │
  ├─ GET /status       当前包、启停、待审、最近蒸馏
  ├─ GET /scope        全局 → 项目 → 会话的叠层结果
  └─ GET /inject       真实注入文本与指纹
       │
       └─ EnvironmentContext
            ├─ 运行台消费完整上下文
            ├─ 包详情消费包结构与编辑能力
            ├─ 蒸馏页按需请求 /evidence
            ├─ 度量页按需请求 /metrics
            └─ 分发页按需请求导出状态与历史
```

页面切换只改变当前 view，不重新推断环境。保存规则、预设或作用域后统一执行：

```text
写入成功 → 刷新 scope → 刷新 inject → 更新指纹 → 运行台可验证
```

先使用插件内部轻量路由（hash 或 host 提供的 view state），不要求 Harness 新增外部路由。每个页面有独立渲染函数和测试入口。只有在包库、导出历史或报告历史缺少数据时才补最小接口，现有状态、作用域、注入、度量和证据接口保持兼容。

## 7. 编辑权限

| 数据 | 全局 | 项目 | 会话 |
| --- | --- | --- | --- |
| 包内规则 / 技能 | 只读 | 不复制 | 不复制 |
| 采纳规则 | 可写 | 可覆盖 | 可临时覆盖 |
| 项目额外规则 | 不适用 | 可新建、编辑、删除 | 不适用 |
| 预设成员 | 可写 | 可选择项目覆盖 | 只读显示 |
| 会话启停 | 不适用 | 不适用 | 当前会话临时操作 |
| 导出快照 | 可导出 | 可附带项目快照 | 不直接写入包 |

## 8. 状态与错误处理

- 未安装或无包：运行台显示安装/导入入口，包库提供添加本地包动作。
- 尚未蒸馏：蒸馏页解释扫描范围和隐私边界；度量页显示暂无可复算底稿。
- 作用域冲突：显示覆盖链和最终生效结果，提供跳到来源，不自动合并。
- 注入失败：保留上一次成功指纹，显示本次刷新失败和重试按钮。
- 编辑未保存：离开页面前拦截；保存失败保留表单内容和服务端错误。
- 空项目层：显示项目层尚未创建，并明确写入 `.dsh/workstyle.json`。

## 9. 验收标准

1. 默认进入 `/run`，首屏能确认当前包、作用域、生效规则/技能、预设和指纹。
2. 每个一级页面可独立进入，刷新后能恢复当前页面和作用域。
3. 编辑项目规则后，项目层持久化，运行台作用域和注入指纹同步变化。
4. 切换预设后，技能候选顺序和运行台当前预设即时更新。
5. 蒸馏采纳后，包详情显示来源，运行台注入预览包含该规则；撤销反向成立。
6. 度量中的每个指标带公式、分母、数据窗口和样本边界，不出现“遵守率”或“违反率”。
7. 分发页可以分别导出仅包和带项目作用域快照的包，并显示安装命令。
8. 每个页面覆盖浅色、深色、键盘焦点、空状态、错误状态和减少动效。
9. 现有 `test/smoke.mjs`、`test/panel-render.mjs` 保持通过；新增页面和行为测试覆盖路由、编辑、指纹更新和隐私约束。
10. 包内参考目录不被任何编辑动作写入。

## 10. 明确不做

- 不做跨设备同步或团队在线协作。
- 不使用 LLM 判断规则是否被遵守。
- 不自动解决规则冲突，只展示冲突和来源。
- 不把包内参考资源改成可写目录。
- 不把运行台重新做成包含所有编辑能力的长单页。

## 11. 实施顺序

1. 抽取共享环境上下文和轻量路由，保持现有单页入口可回退。
2. 实现运行台 `/run`，迁移当前状态、待办、注入证明和快速切换。
3. 实现包库与包详情，接入规则/技能/预设/模板现有数据和项目层编辑。
4. 独立实现蒸馏审阅、度量和分发页面。
5. 补齐空态、错误态、键盘焦点、深色主题和页面级测试。
6. 运行 smoke、panel-render 和新增多页面验证，完成真实 Harness 截图复核。
